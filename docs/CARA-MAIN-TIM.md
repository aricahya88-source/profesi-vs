# Cara Main Tim — v1.2

## Struktur

- Tim A: A1, A2, A3, A4
- Tim B: B1, B2, B3, B4

## Pasangan babak

1. A1 vs B1 — Pilihan Ganda (10 soal per sisi)
2. A2 vs B2 — Benar/Salah (10 soal per sisi)
3. A3 vs B3 — Menjodohkan (5 soal per sisi)
4. A4 vs B4 — Pilihan Lebih dari 1 (10 soal per sisi)

## Aturan v1.2

- Soal sisi A dan B **berbeda** ketika dimainkan.
- Setiap sisi berjalan mandiri. A tidak perlu menunggu B untuk masuk soal berikutnya.
- Jawaban yang sudah dipilih langsung terkunci.
- Setelah sekitar 0,85 detik, soal berikutnya muncul otomatis.
- Pembahasan dan kunci jawaban **tidak ditampilkan** selama pertandingan.
- Jika salah satu sub-tim menyelesaikan seluruh soal babak lebih dahulu, layar sisi tersebut menjadi mode menunggu.
- Babak berikutnya baru dimulai setelah kedua sub-tim menyelesaikan babaknya.
- Skor A1–A4 dijumlahkan menjadi skor Tim A; skor B1–B4 menjadi skor Tim B.
